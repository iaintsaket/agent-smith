# Agent Smith 🤖

> A living field guide to the modern AI engineering stack — from LLM fundamentals and RAG to agents, model training, evaluation, and production operations.

**Agent Smith** is an evolving learning tracker and practical reference for understanding the concepts, tools, patterns, and trade-offs shaping AI engineering. It is designed to be useful both as a structured learning roadmap and as a glossary you can return to while building real systems.

This repository is intentionally a **work in progress**. We will keep updating it as the ecosystem evolves: adding useful concepts, improving explanations, refreshing references, recording practical lessons, and separating durable engineering ideas from short-lived buzzwords.

## What's covered

The tracker is organized around these areas:

1. **Foundations** — LLM basics, tokens, transformers, attention, embeddings, context windows, and sampling.
2. **Building with LLMs** — Prompt and context engineering, RAG, retrieval, vector databases, structured outputs, and application frameworks.
3. **Agents** — Tool use, agent loops, planning, memory, orchestration, and multi-agent patterns.
4. **Models and reasoning** — Model families, reasoning approaches, inference, and model-selection trade-offs.
5. **Training and customization** — Fine-tuning, adaptation methods, datasets, and evaluation during model development.
6. **Production and LLMOps** — Deployment, observability, latency, cost, reliability, testing, and operational practices.
7. **Safety and the bigger picture** — Security, privacy, governance, alignment, and responsible use.
8. **Tools to try** — A practical shortlist of tools and platforms worth exploring.

The tracker also includes practical production checklists, a metrics glossary, a reading shelf, a maintenance log, and open questions to investigate.

## How to use the tracker

- Mark a topic complete only when you can explain it clearly and recognize when it is useful—not just after reading its definition.
- Use the in-progress marker while actively learning a topic.
- Add implementation notes, architecture examples, debugging stories, and trade-offs from real projects.
- Prefer primary documentation and technically detailed sources; revisit links as products and APIs change.
- Treat emerging terminology and vendor language critically. A popular label is not automatically a new engineering discipline.

The Markdown tracker defines the status and priority conventions in more detail.

## Keeping this repository current

This is a **living repository**, not a one-time list. We intend to keep maintaining it over time by:

- adding relevant AI and software-engineering concepts as they become useful;
- refining definitions and examples when our understanding improves;
- updating or replacing stale documentation, videos, and other references;
- adding hands-on experiments, production lessons, and implementation patterns;
- reviewing hype-heavy terms and marking uncertainty where the engineering value is not yet clear.

Suggestions, corrections, and useful resources are welcome. If you spot an outdated link, an unclear explanation, or a concept worth adding, open an issue or propose a change.

## Guiding principles

- **Understand before memorizing:** focus on the underlying problem, mechanism, and trade-offs.
- **Practical over fashionable:** prioritize concepts that help build, evaluate, secure, and operate real systems.
- **Evidence over hype:** distinguish established techniques from emerging ideas and marketing terminology.
- **Continuously improve:** keep the tracker useful as both the technology and our understanding change.

## Project status

The tracker is actively evolving. Sections and completion markers reflect the current state of the learning notes, not an authoritative ranking of technologies or a claim that the material is exhaustive.
